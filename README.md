# РЕЖИМ — Калькулятор режимов резания

Рабочее русскоязычное веб-приложение для ручных токарных и фрезерных станков. Без платных сервисов, аккаунтов, внешних библиотек и серверной базы данных. Первая версия включает калькуляторы, профили 16К20/6Т80ШС, справочники, собственные инструменты с геометрией, диапазоны рекомендаций, избранное, историю и офлайн-режим PWA.

## Быстрый запуск на Windows 10

1. Распакуйте весь архив в обычную папку, например `C:\Rezim`. Не запускайте файлы прямо из ZIP.
2. Если Python ещё не установлен, установите **Python 3.12** с [официального сайта](https://www.python.org/downloads/windows/). При установке включите **Add Python to PATH**. После первоначальной установки Python интернет для калькулятора не нужен.
3. Дважды щёлкните **Start-Windows.bat**. Откроется браузер и окно сервера. Окно сервера оставьте открытым.
4. Если браузер не открылся, введите `http://localhost:8000`. Используйте современный Edge или Chrome. Если порт занят, выполните `py -3 server.py --port 8001 --open` из папки проекта.
5. Остановить сервер: Ctrl+C в его окне. Для следующего запуска снова откройте `Start-Windows.bat`.

Не открывайте `index.html` двойным щелчком: JavaScript-модулям нужен HTTP/HTTPS. Node.js для использования приложения не требуется.

## На iPhone

Приложение работает в современном Safari, а офлайн-установка требует **HTTPS**.

1. Разместите статические файлы на HTTPS-хостинге: например, GitHub Pages. В репозитории должны быть `index.html`, JS/CSS, `sw.js`, манифест и три файла иконок. Python-сервер на таком хостинге не нужен.
2. Для GitHub Pages: загрузите проект в свой GitHub-репозиторий, затем Settings → Pages → Deploy from a branch → ваша ветка → `/ (root)` → Save. Откройте HTTPS-адрес, показанный GitHub. Размещение может быть публичным; в исходниках нет ваших локальных режимов. Хостинг в рамках разработки **не опубликован**.
3. На iPhone откройте этот адрес в **Safari**. Дождитесь надписи **«Готово без интернета»**. Она означает, что ресурсы сохранены в кэше приложения.
4. «Поделиться» → **«На экран Домой»** → «Добавить». Откройте созданную иконку. Для проверки включите авиарежим и выполните расчёт.
5. На первом открытии после установки проверьте данные. Safari и установленное приложение могут иметь отдельные хранилища. Переносите настройки через экспорт/импорт JSON.

Для временного доступа с iPhone в одной Wi‑Fi-сети запустите на компьютере `py -3 server.py --bind 0.0.0.0`, разрешите входящие подключения **только в частной сети** и откройте в Safari `http://IP-компьютера:8000`. Этот вариант требует работающего компьютера и **не обеспечивает офлайн-кэш на iPhone**. Публично выставлять локальный HTTP-сервер не требуется.

Проверены Chromium и экран шириной 390 px, а также офлайн-перезагрузка и расчёт. Физические iPhone и Windows 10 в среде разработки отсутствовали; нативный Safari и BAT-файл на Windows не запускались.

## На Android

1. Откройте тот же HTTPS-адрес приложения в современном **Chrome**. Для телефона локальный адрес компьютера по HTTP не подходит для офлайн-установки.
2. Дождитесь статуса **«Готово без интернета»**.
3. Меню Chrome **⋮ → «Установить приложение»** или **«Добавить на главный экран» → «Установить»** (название зависит от версии Android/Chrome). Если пункт пока не появился, продолжайте использовать браузер; после полной загрузки повторите установку.
4. Запустите иконку «Режим» с главного экрана. Включите авиарежим и проверьте расчёт.
5. Для переноса профилей с компьютера или iPhone используйте JSON-экспорт и импорт в «Справке и данных». Автоматической синхронизации нет.

Отдельный APK не требуется. Это устанавливаемое веб-приложение PWA; оно работает на Android через браузер и с главного экрана. Проверена мобильная компоновка в Chromium, но физическое Android-устройство в среде отсутствовало.

## Первый расчёт

1. **Мои станки**: введите обороты и рабочие подачи из паспорта и табличек именно вашего исполнения станка. Записывайте ступени через пробел или `;`: `0,1; 0,2; 0,3`. Запятая обозначает десятичный знак. Продольные и поперечные подачи 16К20 вводятся отдельно; шаги метрической резьбы — отдельным списком. Для 6Т80ШС подача указывается в мм/мин, без быстрого хода.
2. Заполните границы оборотов, мощность и источник. Отметка «Я сверил данные» означает **вашу** сверку, а не независимую паспортную проверку.
3. **Калькулятор**: выберите операцию и материалы, задайте Vc, подачу и глубину по каталогу инструмента для условий работы. Можно ввести фактическую ступень оборотов вручную, если профиль пока не заполнен.
4. Нажмите **Рассчитать режим**. Смотрите фактическую скорость и подачу после округления к ступеням. Если доступной ступени не существует, программа сообщает об этом вместо округления вверх.
5. Сохраните удачный режим. История хранит до 200 последних успешных расчётов. Повторное использование загружает параметры и требует нового расчёта по текущему профилю.

## Что рассчитывается

- Продольное точение, подрезка торца, растачивание, канавка, отрезка, однозаходная метрическая резьба.
- Концевые, торцевые, дисковые, шпоночные фрезы и фрезы со сменными пластинами.
- Теоретические обороты, ближайшая ступень снизу, фактическая скорость, подачи на оборот/зуб и в минуту.
- Учитываются пределы оборотов станка и заданный предел всей инструментальной сборки. Ручная корректировка не обходит ограничения.
- Для фрезерования после подбора ступени минутной подачи пересчитывается фактическая подача на зуб.

Точные кинематические формулы:

```text
n = 1000 × Vc / (π × D)            [об/мин]
Vc факт = π × D × n / 1000         [м/мин]
Vf точение = f × n                [мм/мин]
Vf фрезерование = fz × z × n       [мм/мин]
fz факт = Vf / (z × n)            [мм/зуб]
```

`D` — диаметр в мм; `z` — число зубьев. Для однозаходной метрической резьбы `f = P`, где P — шаг в мм; для многозаходной и дюймовой резьбы эта версия не предназначена. Глубина при обычном точении — радиальная: уменьшение диаметра равно `2 × ap`. При резьбе — радиальное врезание за проход. Для канавки и отрезки ширина кромки проверяется отдельно. При подрезке и отрезке Vc уменьшается к центру; автоматического поддержания скорости у станков нет.

## Рекомендации и достоверность данных

**Паспортные числовые таблицы и универсальные режимы не предзаполнены.** Попытки открыть технические источники при разработке получили `403 Forbidden` от сетевого прокси. Не было возможности проверить исполнение станков, таблицы и диапазоны; они не заменены выдуманными значениями. Ссылки и статус проверки находятся в [SOURCES.md](SOURCES.md) и в приложении.

Справочник содержит названия Сталь 3/20/35/45/40Х, нержавеющих сталей, чугуна, алюминия и его сплавов, латуни, бронзы, меди и пластиков. Для каждой заготовки можно уточнить твёрдость, состояние поставки и источник. Числовая геометрия инструмента заполняется по паспорту или измерениям; качественные пояснения не являются таблицей углов заточки.

В **Материалах** можно сохранить подтверждённые диапазоны Vc, подачи и глубины для конкретной операции, материала, класса/типа инструмента и черновой/чистовой обработки. Обязательны источник и условия: твёрдость, марка инструмента, покрытие, СОЖ, ae/D, вылет и жёсткость. Калькулятор показывает диапазон и позволяет **явно** подставить нижние границы. Даже нижняя граница не гарантирует отсутствие перегрузки. При выходе фактического режима из сохранённого диапазона появляется предупреждение.

Глубина и Vc не могут быть инженерно рекомендованы только по названию материала. При отсутствии диапазона это входные данные оператора. Мощность двигателя сохранена как характеристика; проверка потребляемой мощности не выполнена без удельной силы резания, КПД и сведений о состоянии станка.

## Ваши данные и офлайн-работа

Профили, материалы, инструменты, диапазоны, сохранённые режимы и история хранятся в `localStorage` этого браузера. Сервера синхронизации нет. В **Справке и данных** экспортируйте JSON для резервной копии или переноса между Windows, iPhone и Android. Импорт проверяет структуру и требует подтверждения замены локальной мастерской.

Очистка браузера, удаление приложения, приватный режим и смена адреса сайта могут привести к потере данных. Офлайн-кэш хранит файлы приложения, а не внешние справочные сайты. Если браузер не разрешает сохранение, программа сообщает об этом: экспортируйте данные перед закрытием.

При обновлении файлов разработчик должен изменить версию `CACHE` в `sw.js`; после загрузки новой версии старый кэш приложения удаляется. Хранилище пользовательских данных при этом остаётся прежним.

## Разработка и проверки

Никаких зависимостей устанавливать не нужно. Python 3.10+ нужен только для локального сервера, Node.js 18+ — для тестов формул.

```sh
python3 server.py
npm test
```

Для браузерной проверки нужен Node.js 22+ (встроенный WebSocket), Chrome/Chromium с DevTools и **изолированным тестовым профилем**:

```sh
chromium --headless --remote-debugging-port=9222 --user-data-dir=/tmp/rezim-test about:blank
node tests/browser-smoke.mjs
```

Тест предполагает локальный сервер на порту 8000; другой адрес задаётся переменной `TEST_URL`. Он очищает данные тестового сайта, создаёт синтетические профили и проверяет оба калькулятора, справочники, рекомендации, историю, сохранение при перезагрузке, ширину экрана и расчёт без сети. Не запускайте его в обычном личном профиле Chrome. В контейнере Chromium может требовать дополнительных параметров запуска.

Файлы проекта: `engine.js` — чистые расчёты; `data.js` — справочник и пустые профили; `storage.js` — проверка данных; `app.js` — интерфейс; `sw.js` — офлайн-кэш. Сборка не требуется.
