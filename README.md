# Режим — калькулятор резания

Русскоязычное веб-приложение для ручных станков **16К20 и 6Т80**. Опубликовано: **https://canonsila99-prog.github.io/1/**. Работает в браузерах Windows 10, iPhone и Android; аккаунт и установка Python для опубликованного сайта не нужны.

## Использование

1. Выберите станок и операцию.
2. Выберите реальные обороты из выпадающего списка. Для автоматического подбора выберите «Подобрать по скорости Vc» и укажите целевую скорость из каталога инструмента.
3. Введите диаметр, подачу и глубину; для фрезерования также число зубьев и ширину.
4. Нажмите «Рассчитать режим»: крупно показаны обороты, фактическая подача, глубина и скорость резания.

Материал, инструмент, дополнительные ограничения и пояснения доступны в раскрывающихся настройках. Можно сохранять свои материалы, инструменты с геометрией, подтверждённые диапазоны режимов, результаты и историю. Данные локальны; для переноса между устройствами используйте экспорт/импорт JSON в «Справке».

## Заполненные станки

- 16К20: **22 прямые скорости, 12,5–1600 об/мин**, 11 кВт. Подачи учитывают диапазоны оборотов и увеличение шага ×1/2/8/32. Обратные скорости и справка о передачах показаны в данных станка.
- 6Т80: **12 скоростей, 50–2240 об/мин**, 3 кВт, 18 горизонтальных и 18 вертикальных подач. Данные основного горизонтального шпинделя, без отдельного профиля ШС.
- В первичном скане 6Т80 горизонтальная ступень напечатана **325 мм/мин**; она отмечена как спорная и требует сверки с табличкой. Программа не исправляет возможную опечатку предположением.

Источники, таблицы и ограничения: [SOURCES.md](SOURCES.md). Ряды не восстановлены по минимуму/максимуму. Числовые режимы конкретных инструментов и углы заточки не выдуманы: для рекомендации требуется диапазон с источником и условиями. Нагрузка и состояние станка не моделируются.

Обновление автоматически заполняет старые пустые заводские профили и сохраняет собственные настройки, материалы, инструменты и историю. Список ШС переименуется в один профиль 6Т80; собственные числовые данные не заменяются заводскими.

## Без интернета

Первый раз откройте сайт с интернетом и дождитесь «Готово без интернета».

- **Windows 10:** используйте Edge или Chrome; при желании установите сайт как приложение через меню браузера.
- **iPhone:** Safari → «Поделиться» → «На экран Домой». Откройте иконку и проверьте расчёт в авиарежиме.
- **Android:** Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран». APK не нужен.

Кэшируются все файлы приложения, без внешних шрифтов и библиотек. Внешние справочные страницы требуют интернет. Очистка браузера может удалить данные: сохраняйте JSON-копию. Автоматической синхронизации между устройствами нет.

## Локальный запуск на Windows 10

Для опубликованного сайта эти шаги не нужны. Для запуска из файлов:

1. Распакуйте проект, например в `C:\Rezim`.
2. Установите Python 3.12 с официального сайта, включив **Add Python to PATH**.
3. Запустите **Start-Windows.bat**. Оставьте окно сервера открытым; браузер откроется автоматически.
4. Если браузер не открылся, введите `http://localhost:8000`. Остановка сервера — Ctrl+C.

Не открывайте `index.html` двойным щелчком: модулям нужен HTTP/HTTPS. Для телефонов первоначальная офлайн-установка требует HTTPS; обычный HTTP-адрес компьютера в Wi-Fi этого не обеспечивает.

## Разработка и проверки

Внешних зависимостей и сборки нет. Python 3.10+ — для локального сервера, Node.js 18+ — для тестов формул:

```sh
python3 server.py
npm test
```

26 автоматических тестов проверяют формулы, выбор ступеней и ограничения, ряды паспортных значений, зависимость подач от оборотов, вертикальную подачу, миграцию и сохранение расчётов. Браузерная проверка требует Node.js 22+ и Chromium с изолированным профилем:

```sh
chromium --headless --remote-debugging-port=9222 --user-data-dir=/tmp/rezim-test about:blank
node tests/browser-smoke.mjs
```

Проверка использует локальный сервер на 8000 (либо `TEST_URL`), очищает только данные тестового сайта и проверяет оба полных списка оборотов, расчёт без введённого Vc, справочники, историю, JSON-импорт, ширину 390 px и перезагрузку/расчёт без сети. Не запускайте её в личном профиле браузера. В контейнере могут понадобиться дополнительные параметры Chromium. Физические Windows, iPhone, Android и нативный Safari здесь не тестировались.

`engine.js` — формулы; `data.js` — справочники; `storage.js` — проверка и миграция данных; `app.js` — интерфейс; `sw.js` — офлайн-кэш. При изменении приложения меняйте версию кэша и в `sw.js`, и в проверке готовности `app.js`. Для публикации GitHub Pages используются ветка `main`, корень репозитория и `.nojekyll`.
